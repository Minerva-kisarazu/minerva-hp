# 指導報告書から抽出した知見

`report.csv`（521件・約107,000文字）を全件通読して構造化したもの。
サイトの文言を書くときの**一次資料**として使う。抽象的なキャッチコピーを書きそうになったら、
ここに載っている実際の観察語彙に置き換えられないかを先に確認する。

## 0. データの範囲

| 項目 | 内容 |
| --- | --- |
| 件数 | 521件（1件＝1コマの授業報告） |
| 総文字数 | 約107,000字（1件平均206字） |
| 期間 | 2026/2/23 〜 2026/8/21（約6か月） |
| 学年 | 中2:141 / 中3:114 / 小6:69 / 中1:66 / 小5:53 / 高3:42 / 小4:34 / 小3:2 |
| 科目 | 数学:166 / 英語:141 / 国語:110 / 算数:76 / 国算同時:15 / 理科:8 / その他複合 |

氏名・学校名は含まれていないため、リポジトリで管理しても個人が特定されることはない。

## 1. 報告書そのものの「型」

ほぼ全件が同じ4要素で構成されている。これ自体がミネルバの指導の可視化になっている。

1. **今日扱った範囲** —「本日は一次関数の続きを扱いました」
2. **できたこと（具体的に）** —「後半の教科書表現は全問正解で素晴らしいです」
3. **つまずきの観察と原因の推定** —「yの増加量を求める問題でxの増加量を代入していた」
4. **次の一手・家庭への依頼** —「用語を整理しておきましょう」「次回テスト答案を持ってきてください」

つまりこれは「今日は○○をやりました」という**授業日誌ではなく、毎回の診断書**である。
サイトで「学習プロセスを分析する」と書いていることが、文章として実際に毎回実行されている。

## 2. 頻出のつまずきパターン

出現頻度の高い順。カッコ内は該当キーワードを含む報告書の件数（目安）。

### A. 「聞けば分かる」のに「自分ではできない」（59件、体感では最頻出）

最も繰り返し現れるパターン。**学力が足りないのではなく、知っていることを自分で発動できない**状態。

> 「説明しているときや詰まった時の問いかけは正しく答えられるのですが、自分でゼロから解くとなると三角形の時の解き方をそのまま当てはめてしまいます」

> 「一つ一つの質問は答えられても自力では解けなかった」

> 「もう一回読み直してと伝えただけで正答にたどり着くことが出来ました」

> 「指摘すれば読み取ることは出来ていて」

これはサイトで最も強く言うべき発見。「勉強しているのに伸びない」の中身がこれ。

### B. 途中式を書かない／頭の中で処理する（38件）

数学・算数の失点の最大の直接原因として繰り返し名指しされている。

- 「途中式を書かないことで見落としが発生している」
- 「頭の中でやろうとすると時間がかかったり間違えたりする」
- 「ノートを贅沢に使ってどんどん書き加えていく」
- 「基本的には消しゴムを使わずに全部ノートに残す。どこで間違えたかを知ることも大切」
- 「一見書く量が多くめんどくさいように見えますが、結果的に早く解けますし疲れにくい」

面倒に見える作業が実は速い、という説明の仕方をセットで使っている。

### C. 手順の暗記だけで意味を考えない（73件）

「なんとなく」「適当に」「とりあえず」という語で記述されるパターン。

- 「解き方を覚えて当てはめる習慣が強過ぎて、意味を考えることや試行錯誤してみることができなくなっている」
- 「前の問題の式の数字だけ変える方法に頼ってしまう」
- 「なんとなく大きい数字を小さい数字で割ってしまった」
- 「出会うと追いつくの違いを一切考えずに解いていて、速さの差で割るのか和で割るのか二択のクイズのようになってしまった」
- 「適当に数字を当てはめるモードになってしまって見当違いな計算をする」

一度解いた形は解けるが、少し条件が変わると完全に停止する。

### D. 設問を読まない／問われたことに答えない（71件）

科目横断で最も広く見られる失点原因。

- 国語：「一文を抜き出せ」で段落を丸ごと抜き出す／字数指定を無視する／抜き出し指示なのに自分の言葉で書く
- 数学：xを求めて満足して設問の答えを書かない／求める値の片方を出し忘れる
- 「残りのページ数を聞かれているのに全体のページ数を答えてしまう」
- 対策として「答えを書く前に問いを再確認する」「設問の指示に丸をつける」を反復指導

### E. 英語を「音の記憶」で書く（be動詞関連32件・語順30件）

- 「なんとなく疑問文だからDoから、みたいな感じで書いてしまっている」
- 「音で思い出すのではなく法則に従って書き換えることを徹底しましょう」
- 「you are play のようにbe動詞と一般動詞を混在させてしまう」
- 「聞き覚えのある表現、口をついて出る表現に引っ張られている」

### F. 国語の論理関係が未定着（35件）

因果・抽象具体・対比・譲歩の4つが繰り返し出てくる。

- 「接続語を入れる問題は全て合っていたのに、その意味関係を問う問題は全滅」
  → 言葉として聞き覚えはあるが、関係を理解していない
- 「確かに・しかし のような譲歩の構造に慣れていない」
- 「本文と設問で書き方が違う（○○がその代表的な例でしょう／代表的な例として○○が挙げられる）と考えられない」
- 「知らないと言うよりは、自分が分からないテーマについての文章を論理関係から読み解くという行為をしていない」

### G. 前学年・小学校範囲の穴が上の学年を止めている（分数39件・単位20件）

中学生の数学が進まない原因が小学校範囲にあることが何度も記録されている。

- 「1/2が1の半分であることや3/2が1と2の中間であることが分かっていなかったため、数直線を用いて分数概念を復習」
- 「4時間30分が4.5時間になることや、時速60kmが分速1kmになることが腑に落ちていない」
- 「そもそも15が15.0であることが分かっていなかった」
- 「九九で間違えるのは勿体ない」
- 中3で「16a=4 が解けず、中2範囲の等式の変形が怪しいことが分かった」

### H. 学習の作法・生活面（宿題203件・集中20件・暗記22件）

- **宿題の定義**：「解くだけでなく丸付けとやり直しまでやるのが宿題です」「やりっぱなしだと元々解ける問題が解けただけでほとんど意味がありません」
- **タイミング**：「宿題はやり方を覚えているうちになるべく早く取り組んでください」（間が空くと前提が消える）
- **答えを見る癖**：「解き切るまで何も見ずに取り組みましょう。ヒントを見る癖がつくとテストで解けなくなります」「答えではなく解き方を調べてください」
- **到達点の定義（高3）**：「問題文以外何も見ずに最初から最後まで答案を書けた状態が、その問題をやったということになります」
- **観察対象が学力にとどまらない**：眠気、手遊び、時計を見る頻度、ペンの持ち方と筆圧、他の生徒がいると恥ずかしがる、涙ぐんで来塾した様子まで記録し、必要なら家庭に連絡している

## 3. 実際に行っている介入の型

サイトで「教えすぎない」「思考プロセスを扱う」と書いている中身の実物。

### 型1：問いかけて自分で言語化させる

決まったフレーズを反復して使っている。

- 「一言で言うと？」「何の話をしてた？」「何と何を比べてる？」「なんで？」「たとえば？」
- 「この長さは何を表している？」「今問われているものはどの長さ？」
- 「この式は何を計算してる？」「どこの面積？」
- 「6の倍数は？」のように定義そのものを問い直す

### 型2：情報を外に出す手順を固定する

- 速さ・割合 → **道のり／速さ／時間の表を作ってから式を作る**
- 食塩水 → **①食塩水の重さ ②食塩の重さ**
- 関数・図形 → **まず図を書き、問題文の条件を書き込み、求められる座標は全部求める**
- 比 → **線分図に数字だけでなく範囲も書き込む**
- 2桁の整数 → **十の位x・一の位y・元の数10x+y・入れ替えた数10y+x は毎回同じなので覚える**
- 分からない値 → **探すのではなく文字に置いて成り立つ式を作る**（数学の基本方針として繰り返し明言）

### 型3：処理を機械化して迷いを消す

「意味を考えさせる」一方で、迷う余地を消すために意図的に機械化する箇所を切り分けている。

- 「移項は機械的に処理していく」
- 「be動詞なら前に出す、一般動詞ならDo/Doesをつける、という基本法則をとにかく覚えてその通りにやる」
- 「否定文・疑問文への書き換えは単語の意味を一切知らなくてもできるボーナス問題」
- 「比較を無視して基本の英文を作ってから more や as を付け足す」
- 「疑問文は肯定文を作ってから順に書き換える」
- 「不定詞の3用法は意味ではなく文法で判別する。SOCなら名詞、名詞を修飾なら形容詞、どちらでもなければ副詞」
- 「証明は型が決まっているので型通りに書く。省略はNG」

### 型4：覚え方そのものを教える

- 「無駄に何回も書く必要はない。毎回手本を隠してテストだと思って書く」
- 「1個をじっくり見るのではなくどんどん進めて何度も復習する。覚えられていない単語にだけ時間をかける」
- 「訳す練習 → 単語を言う練習 → 書く練習の順」
- 「共通点や相違点、規則性と例外を考えながら見る」
- 「大枠から少しずつ細かくしていくイメージで覚える」

### 型5：集中・体調への具体的な処方

- 「勉強を始めてしばらくすると眠くなるのは自然なので、むしろ一旦机で寝てしまうと良い。15〜20分で起きると一番集中できる」
- 「25〜30分ごとに5分休憩。切りの良いところではなくむしろ途中で休む」
- 「そのページを解き終わるまで顔を上げずに取り組む」

## 4. 保護者への説明で使っている語彙・トーン

サイトの文体をこれに寄せると、実物とサイトの声が一致する。

**断定を避ける** — 「印象です」「ようです」「かと思われます」「見受けられます」を多用し、観察と推定を区別している。

**必ず具体的に褒める** — 抽象的な励ましではなく行動を挙げる。
> 「しっかり書き込みながら問題に取り組んでいますし字も丁寧です。説明時に分からないときは頷かないため、きちんと理解しようとする姿勢も見て取れる」

**原因を能力に帰さない** — 「わかっていないわけではなさそう」「能力ではなく自信・姿勢の問題」のように、
つまずきを習慣・手順・作法の側に置く。

**家庭への依頼は行動レベル** — 「理社は1日1単元」「英語は読解1日1題」「次回テスト問題と答案を持ってきてください」
「BUILDERは毎日1項」など、判断を求めず動作を指定する。

**成長は差分で語る** — 「これまでに比べると途中式を書いてくれることが増えた点は非常に素晴らしいです」
「指示していなくても図形に分かっている角度を書き込めるようになっている点で良い変化」

**言い切って前向きに終える** — 「解ける問題を落とさないことが何よりも大切」「満点を目指して細心の注意を払って臨んでください」

## 5. サイトの文言に反映すべきこと

### 5-1. 抽象語を実際の観察語に差し替える

| サイトの抽象表現 | 報告書にある実物 |
| --- | --- |
| 学習プロセスを分析する | 途中式を書かないから符号を落とす／前の問題の式の数字だけ変える／英語を音の記憶で書く／設問を読まず近くの語を拾う |
| つまずきの原因を特定する | 中3の関数が止まる原因が中2の等式変形、さらに小学校の分数概念にある |
| 自分で考える力を育てる | 「一言で言うと？」「この式は何を計算してる？」と問い、答えを言わずに待つ |
| 学習習慣を定着させる | 宿題は丸付けとやり直しまで。やり方を覚えているうちに早く着手する |

### 5-2. 「宿題の定義」は未活用の強い差別化材料

「解く→丸付け→やり直しまでが宿題」「やりっぱなしでは元々解ける問題が解けただけ」という考え方は
報告書で203件に登場する中心的な指導方針だが、サイトにはまったく書かれていない。
指導方針ページか学年別ページに1ブロック立てる価値がある。

### 5-3. 事例セクションは点数より変化のプロセスで語る

報告書には点数の記録がほとんどなく、あるのは行動の変化。
「38点→72点」型の数値訴求よりも、
「途中式を書かない → 縦に式変形して残す → 符号ミスが消える」のようなプロセス提示のほうが実物に忠実で、
かつ保護者にとって「わが子に当てはまるか」が判断しやすい。

### 5-4. 学年別ページに入れる具体材料

- **小学生**：分数の概念（1/2が1の半分）、単位換算、設問の読み方（「一文を抜き出せ」）、
  記述は「一言で答えてから付け足す」、論理関係（因果・抽象具体・対比）を短文で練習してから長文へ
- **中学生**：be動詞と一般動詞の切り分け、語順（まず主語と動詞）、途中式を残す、
  学校ワークを進度に合わせて進めテスト前は覚えるだけの状態にする、前学年の穴の埋め直し
- **高校生**：進める量の指定（1日4題／10ページ）、英文の構造分析、
  「何も見ずに答案を最後まで書ける」を到達基準にする、総合型選抜を見据えた志望校の絞り込み

### 5-5. Q&Aに追加できる候補

- 「宿題はどれくらい出ますか？」→ 量よりも「丸付けとやり直しまで」という定義を答える
- 「うちの子は聞けば分かるのに点数が取れません」→ 報告書の最頻出パターンそのもの
- 「前の学年の内容から戻ることはありますか？」→ 戻る。中3の関数が小学校の分数で止まる例を出す
- 「集中力が続かないのですが」→ 眠気・休憩の具体的な処方を答える

## 6. 使うときの注意

- 報告書の文言をそのままサイトに転載しない。生徒個人の記述が混ざるため、必ずパターンとして抽象化する。
- 「できていない」記述が多いのは診断書だからであり、そのトーンをサイトに持ち込むと不安を煽るだけになる。
  サイトでは「その状態をこう扱う」という介入の型（第3章）とセットで書く。
- 数値の裏付けが必要な主張（合格実績・点数上昇）はこのデータからは取れない。書かない。
